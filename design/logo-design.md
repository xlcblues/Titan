# Titan Logo 设计方案

> Titan：基于深度学习的 Windows 桌面三维重建软件，与 Mars、Ceres、Neptune 同系列。
> 本文档记录 Logo 设计概念、几何构成、家族一致性、色彩推导与使用规范，是 UI 主题的唯一依据。

## 1. 设计概念：Facet T（棱面 T）

Titan 命名取自土星最大的卫星「泰坦」，软件核心是把一组二维图片重建为带空间结构的三维场景。Logo 用纯粹的几何语言表达三件事：**字母 T、立体棱面、扫描轨道**。

- **主体是字母 T**：三块清晰可辨识的棱面组成一个立体 T，正面、顶面、右侧面各自可见。棱面同时隐喻三维重建中的三角网格面片，也暗示「从平面影像中重建出立体」这一核心能力。
- **开口扫描轨道弧**：T 上方一条不闭合的弧线，右端带一个圆点。弧线象征相机围绕场景扫描成像，圆点象征一个相机位姿或一个输入视角；开口方向暗示「从照片到场景」的生成路径。
- **极简几何、单色、大量留白**：不出现渐变、纹理与插画，缩到 16px 仍能辨认字母 T 与轨道，与同系列软件的图形语言一致。

## 2. 几何构成

Logo 的 SVG 画布为 `512 x 512`，符号集中在画面中央，四周保留充足留白：

1. **棱面 T 主体**：横臂 `132 x 44`，竖杆 `44 x 132`，位于画面偏下位置，作为视觉重心。
2. **顶面**：从 T 顶边向右上延伸的平行四边形（`0,0 → 132,0 → 180,24 → 48,24`），模拟向下的受光面，形成体积感。
3. **右侧面**：沿 T 右缘与顶面右缘的两块平行四边形，用半透明递进（`1.0 / 0.5 / 0.28`）表现三个棱面的明暗层次，只用同一色相的不同不透明度，不引入第二种颜色。
4. **扫描轨道弧**：半径 `175` 的圆弧从左侧上方跨越至右上，开口向下；右端放置 `r=13` 的相机圆点。

三块棱面 + 一条弧 + 一个点的构成，正好对应三维重建的关键概念：**面片（面片）、轨迹（相机路径）、位姿（相机点）**。

## 3. 家族一致性

Titan 与 Mars、Ceres、Neptune 保持同一套视觉家族语言：

| 项目 | 符号 | 共同语言 | 差异化 |
| --- | --- | --- | --- |
| Mars | 星球 + 轨道 + 卫星点 | 极简几何、单色、弧线轨迹、圆点 | 暖锈红星球 |
| Ceres | 空心圆弧 C + 中心点 | 弧线、圆点、单一色相层次 | 谷绿 + 收获金 |
| Neptune | 三叉戟立柱 + 底部轻弧 | 立柱结构、弧线、单色 | 海蓝三叉戟 |
| **Titan** | 棱面 T + 扫描轨道弧 + 相机点 | 弧线、圆点、单一色相层次 | 霜青立体 T |

共同点：全部为单色极简几何、以一条弧线或轨道连接元素、使用圆点承载语义、深浅主题各有变体。Titan 的差异点是「立体棱面」：它是家族中第一个带体积感的符号，正好呼应三维重建的产品身份。

## 4. 从 Logo 推导主题色

主色取自「霜青」——一种介于青与绿之间的冷色，来自棱面 T 的正面与轨道弧。它同时给人「冰面、扫描光、数据、寒带卫星」的印象，与 Titan 的大气与工程感匹配。

| Token | 色值 | 角色 |
| --- | --- | --- |
| `titan.frost` | `#0FA896` | 主色，Logo 主体、导航选中、主按钮、图表主色 |
| `titan.ice` | `#2ED3BE` | 强调色，深色模式主按钮、关键指标、扫描进度 |
| `titan.deep` | `#0B7A70` | 深青，悬浮高亮、渐变端点、深色强调文字 |
| `titan.midnight` | `#101820` | 深色模式窗口底色（深石墨墨蓝） |
| `titan.coal` | `#18232D` | 深色模式卡片与悬浮层 |
| `titan.paper` | `#F2F4F1` | 浅色模式窗口底色（冷白纸感） |
| `titan.paper-2` | `#FBFCFA` | 浅色模式卡片底色 |
| `titan.ink` | `#152027` | 主文字（冷墨） |
| `titan.muted` | `#5F6C73` | 次级文字（冷灰） |

配色逻辑：

- 浅色模式：冷白纸感背景 + 冷墨文字 + 霜青结构 + 冷灰次级信息。
- 深色模式：深石墨墨蓝背景 + 冰白文字 + 亮霜青强调 + 半透明白玻璃层级。
- 霜青只用于「选中、关键操作、扫描中、数据高亮」，屏幕内主色面积通常不超过 10%，避免界面单色化。

## 5. 文件清单

资产位于 `assets/logo/`：

| 文件 | 用途 |
| --- | --- |
| `titan-symbol.svg` | 透明符号，浅色背景侧边栏、空态、页眉 |
| `titan-symbol-dark.svg` | 透明符号，深色背景 |
| `titan-mark.svg` | 圆角方块应用图标（含霜青符号） |
| `titan-wordmark.svg` | 符号 + Titan 字标，浅色背景启动画面/安装器 |
| `titan-wordmark-dark.svg` | 符号 + Titan 字标，深色背景 |

## 6. 使用规范

- 深色背景使用亮霜青/冰白符号，浅色背景使用霜青符号；不替换主色。
- 安全间距：符号四周至少保留符号高度 25% 的空白。
- 最小尺寸：16px（仅符号），48px（含字标）。
- 不拉伸、不加阴影与渐变外框；应用图标统一使用圆角方块版本。
- 应用图标圆角与家族一致：`rx = 224/1024`。
